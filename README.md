# MKT-CRM 市场部 AI-Native 工作台

明略科技品牌与市场部内部工作台，覆盖 Event 活动、辉哥演讲获客、Octo 大客户、SDR 漏斗四大业务板块。

## 一键部署到 Render

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/fanyue0203-glitch/mkt-crm)

## 本地开发

```bash
npm install
npm start
# 访问 http://localhost:3000
```

## 技术栈

- **前端**: Vanilla JS SPA + Chart.js
- **后端**: Node.js + Express
- **数据库**: SQLite (better-sqlite3)
- **文件上传**: multer + xlsx
